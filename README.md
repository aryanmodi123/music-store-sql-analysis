🎵 Music Store Data Analysis (SQL Project)

About this project

In this project, I analyzed a music store database using SQL to answer real business questions related to customers, sales, and music preferences.

The goal was to practice writing efficient SQL queries while also understanding how data can be used to support business decisions.


Database Overview


The dataset consists of multiple related tables such as:

* Customers
* Invoices & Invoice Lines
* Tracks, Albums, Artists
* Genres & Media Types

This structure helped me practice working with **joins and relational data**.



What I worked on

I solved a set of business-driven questions across three levels:

🟢 Easy

* Senior-most employee
* Countries with most invoices
* Top invoice values
* Best customer & best city

🟡 Moderate

* Rock music listeners
* Top rock artists
* Tracks longer than average

🔴 Advanced

* Customer spending by artist
* Most popular genre by country
* Top customer per country

(Full question set included in the project) 


Key SQL Concepts Used

* Joins (INNER JOIN across multiple tables)
* Aggregations (SUM, COUNT, AVG)
* Subqueries
* CTEs (Common Table Expressions)
* Grouping & Sorting
* Filtering with conditions


Example Insight

* Identified top customers based on total spending
* Found most popular music genres across countries
* Analyzed customer preferences and purchase patterns


What I learned

This project helped me understand how to:

* Work with real relational databases
* Write structured and optimized SQL queries
* Translate business questions into SQL logic
